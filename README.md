# InternHub – Responsive Internship Board

InternHub is a responsive internship board website that helps students explore and discover internship opportunities across different domains.

## 🚀 Project Overview

This project provides a simple and user-friendly platform where students can browse internship listings, search for opportunities and filter them based on different preferences.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Responsive design for mobile, tablet and desktop.
- Internship listings generated using reusable JavaScript data.
- Search internships by role and company name.
- Filter internships by domain.
- Combined search and filtering.
- Sorting and pagination.
- Empty state when no matching internships are found.
- Keyboard navigation and visible focus indicators.
- Accessible form labels.
- Login, signup and internship application demo interfaces.

## 📱 Responsive Testing

The website was tested at the following screen widths:

- Mobile: 360px
- Tablet: 768px
- Desktop: 1366px

## ⚠️ Project Limitations

- Internship listings currently use local sample data.
- Login and signup are frontend demonstrations only.
- Internship applications and posting are not connected to a backend.
- Real-time internship data requires an API or backend integration.
